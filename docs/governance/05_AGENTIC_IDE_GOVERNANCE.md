# Agentic IDE Governance

This applies to Codex, Cursor, Antigravity, and similar tools.

## Agents Must
- respect file scope explicitly
- stop on ambiguity
- ask before expanding scope
- follow governance documents verbatim

## Agents Must Not
- invent abstractions
- infer intent
- refactor without instruction
- silence errors

## Prompt Requirements
All prompts must specify:
- objective
- scope
- constraints
- completion criteria

Non-compliant agent output is invalid.
