# MuseProPark Governance Overview

This folder defines the binding governance rules for the MuseProPark platform.

These documents apply to:
- all human contributors
- all automated or agentic tools (including Codex)
- all future rebuilds, forks, or migrations

## Authority
These governance documents override:
- convenience
- tooling defaults
- individual preference
- undocumented assumptions

If any instruction, tool output, or implementation conflicts with governance,
the conflict must be resolved in favour of governance.

## Scope
Governance applies to:
- product intent
- editorial integrity
- system architecture
- data access
- engineering practices
- deployment
- recovery

No work may proceed without compliance.
